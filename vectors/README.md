# Cross-language vectors

Copied unmodified from the JavaScript SDK
([SDK-JS/vectors](https://github.com/activeledger/SDK-JS/tree/master/vectors)),
which generates them and is the reference implementation. Do not hand-edit;
copy them again when they change upstream.

- `pq-vectors.json` - signatures and keys for secp256k1, ml-dsa-65 and falcon-512
- `seed-vectors.json` - key derivation from seeds and BIP-39 phrases
- `number-vectors.json` - JavaScript number formatting for canonical JSON
